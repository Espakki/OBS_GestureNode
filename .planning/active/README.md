# active/

Plano detalhado da fase **em execução**, um arquivo por fase. Descartável por design:
quando a fase fecha, o arquivo é apagado e o registro passa a ser o commit + a linha no
`STATE.md`.

Se esta pasta está vazia, nenhuma fase está em execução — escolha o próximo item do
`BACKLOG.md`.

Só crie um plano aqui para itens **G** (várias sessões). Item P ou M vai direto pro código.
